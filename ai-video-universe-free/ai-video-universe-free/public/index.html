Free local setup

The app connects to a ComfyUI server running on your own computer. No cloud API keys or paid services are required.

Checking connection…

1. Install and run ComfyUI locally with a compatible open video workflow and model.

2. Export the workflow in API format and save it as workflow.json in this project folder.

3. Copy .env.example to .env, set COMFYUI_URL and COMFYUI_WORKFLOW, then restart this app.

4. In workflow.json, use the placeholders __PROMPT__, __NEGATIVE_PROMPT__, and __SEED__ in text fields/seed fields you want the server to replace.

The exact ComfyUI workflow is model-specific. Image-to-video and video-to-video require the matching input nodes and workflow. This project cannot automatically create a compatible workflow for every model.
